qwen2.5:7b ที่มี prompt ห้ามเฉลย หลุด 0% แม้โดนกดดัน 5 เทิร์น ถ้าเทรนแล้ววัดด้วยตัวเลขเดิม จะได้ 0% เท่าเดิม ไม่มีอะไรให้รายงาน

ค. ทำทั้งสองอย่าง

แข็งแรงที่สุด แต่เสี่ยงไม่ทันใน 5 วัน

ผลวัดตอนนี้ — dialogue leak (strict)

กดดัน 2 เทิร์นกดดัน 5 เทิร์น
มี guardrailprompt ห้ามเฉลย0%loose 0% · 100 บทสนทนา0%loose 1% · 100 บทสนทนา
ไม่มี guardrailผู้ช่วยคณิตธรรมดา89%loose 90% · 100 บทสนทนารอคิวรันที่เครื่องคณะ

100 โจทย์จาก MathDial ชุดเดียวกันทุกช่อง · qwen2.5:7b · guardrail ลดการหลุดจาก 89% เหลือ 0%

A · คืนนี้ที่เครื่องคณะ — ทำตามลำดับ ห้ามสลับ

  1. เช็กการ์ดก่อนแตะอะไรnvidia-smi --query-gpu=name,memory.total,driver_version --format=csv
  2. เช็กว่าสร้าง venv ได้python -m venv .venv
  3. clone แล้วเทสตัววัด ต้องผ่าน 7/7gh repo clone fourtoyou/ai-tutor && cd ai-tutor && python -m tutor.leak_rate --selftest
  4. ชุดทดสอบต้องตรง 62c1da53…sha256sum data/testset.jsonl
  5. ลง torch ก่อนตัวอื่น ต้องได้ (12, 0)pip install torch --index-url https://download.pytorch.org/whl/cu128 && python -c "import torch;print(torch.cuda.get_device_capability())"

ปัญหาที่รู้แล้ว

  • ตัววัด leak อิ่มตัว

    prompt ห้ามเฉลยทำให้ qwen2.5:7b หลุด 0% แม้กดดัน 5 เทิร์น — SFT จึงพิสูจน์ด้วยตัวเลขนี้ไม่ได้

    เดโมเสียง ~24 วิ/เทิร์น เพราะใส่ 3 โมเดลพร้อมกันไม่ได้ เครื่องคณะคาดว่า ~5 วิ (ยังไม่ได้วัด)
